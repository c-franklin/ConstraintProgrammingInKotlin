How the Solver Found This Solution

🧠 Constraint Programming Approach

The CP-SAT solver uses constraint propagation and backtracking to find this solution:

1. Variables: Each column gets one queen. The solver decides which ROW each queen goes in.
2. Row Constraint: All queens must be in different rows (no horizontal attacks).
3. Diagonal Constraints: No two queens can share the same diagonal line.
• Main diagonal: row + col must be unique for each queen
• Anti-diagonal: row - col must be unique for each queen

🔍 Solver Process

Step 1: Try placing first queen (column A). Solver picks a row.
Step 2: For column B, eliminate rows that would attack the A queen.
Step 3: Continue for each column, using constraint propagation to prune impossible choices.
Step 4: If stuck, backtrack and try different placement for previous queens.
